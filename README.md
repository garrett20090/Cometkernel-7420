# Comet Kernel for Exynos 7420 Devices

This kernel is based on [Haldexx's android_kernel_samsung_universal7420](https://github.com/Haldexx/android_kernel_samsung_universal7420).

Custom Linux Kernel tailored for running **One UI 7 (Android 15)** on the Samsung Galaxy Note 5 (`HalleyOS_V` project).

## Known Bugs
- NXP NFC not working (Android 10+)
- QCOM Modem issues

## Building the Source Code
If you want to compile the source code, just type `./comet.sh` in the kernel directory.
The packaged output files will be located in `/Comet/Product`.
